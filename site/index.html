Stop making AI agents re-learn your repo every session.

ironmem gives Codex, Claude Code, and any MCP client a private local memory they share — so they recall what was already explored and decided instead of re-reading the same files each time. One Rust binary, one local SQLite store, no cloud, no account, no Python runtime.

What ironmem gives your agents

Memory that carries across sessions and across harnesses — explore your repo once, not every time.

Recall instead of re-reading

Agents pull up prior context — decisions, file locations, earlier work — through local HNSW vector search, instead of re-exploring the repo each session.

Local and private

Embeddings run on your machine in pure Rust (ONNX via ironrace-embed) — no Python runtime and no external service.

MCP server

Expose status, search, diary, graph, taxonomy, and collaboration tools over stdio.

Knowledge graph

Structured facts and semantic drawers can be queried together as memory grows.

Shared across harnesses

Codex and Claude Code read and write the same local SQLite store by default, so context learned in one is available in the other.

Agent collaboration

Bounded Claude↔Codex planning and coding sessions run over the shared store.

Install ironmem

The source quickstart builds the binary, runs setup, then starts the trusted MCP server.

source quickstart 
git clone https://github.com/ironrace/ironmem.git
cd ironmem
scripts/install-ironmem.sh
~/.ironrace/bin/ironmem setup
IRONMEM_MCP_MODE=trusted ~/.ironrace/bin/ironmem serve

Prebuilt binaries
