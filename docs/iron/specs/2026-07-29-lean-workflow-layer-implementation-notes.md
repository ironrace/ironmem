Companion to `2026-07-29-lean-workflow-layer-design.md`. These are **verified facts** read out of the codebase on 2026-07-29, captured so the implementation plan can cite real extension points instead of inventing APIs. Line numbers are against commit `52b4569`.

## 1. Script conventions to mirror

From `scripts/sync_mcp_wrappers.py` and `scripts/check_site_readme_sync.py`:

- Stdlib only. `from __future__ import annotations` at the top.
- `ROOT = pathlib.Path(__file__).resolve().parents[1]`
- `argparse`, and `if __name__ == "__main__": raise SystemExit(main())`
- Generators take a `--check` flag that compares against expected output and returns 1 on drift, printing `Run: python3 scripts/<name>.py` to stderr (`sync_mcp_wrappers.py:90-101`).
- Exit codes: `0` clean, `1` drift, `2` bad input/unresolvable ref.
- CI-visible failures print a GitHub annotation: `print(f"::error title=<Title>::{detail}")` (`check_site_readme_sync.py:147`).
- Generated artifacts carry a `# Generated by scripts/<name>.py; do not edit by hand.` header (`sync_mcp_wrappers.py:22`).

## 2. Git-hook gate registration — `scripts/git_hook/manifest.py`

Four coordinated edits are required. The `Gate` dataclass validates **domain, not just type**, at import time, so a typo fails loudly rather than silently never running (`manifest.py:320-354`).

1. **Predicate** — add `is_skills_path(path: str) -> bool` alongside `is_collab_protocol_path` (`manifest.py:92`). Match on `/`-split segments, never substrings — the module is explicit that `docsite/` must not match `docs/` (`manifest.py:462-466`).
2. **Surface constant** — add `SURFACE_SKILLS = "skills"` with the others (`manifest.py:274-278`).
3. **Register in `SURFACES`** (`manifest.py:400-408`). **Declaration order is check order** and first match wins. The new surface must be declared *before* `SURFACE_DOCS` and `SURFACE_INERT_CONFIG`, which are generic catch-alls.
4. **Add a `Gate` to `GATES`** (`manifest.py:483+`). Declaration order is execution order; never sorted at runtime. Shape:

```python
Gate(
    name="skills_sync_check",
    argv=("python3", "scripts/check_skills_sync.py"),
    phases=frozenset({PHASE_PRE_COMMIT, PHASE_PRE_PUSH}),
    surfaces=frozenset({SURFACE_SKILLS}),
    always=False,
),
```

### ⚠ Collision to handle deliberately

`scripts/install-ironmem.sh` is **already** in `COLLAB_EXACT_PATHS` (`manifest.py:35`), and `is_collab_protocol_path` is checked before any later-declared surface. So installer edits classify as `collab_protocol`, **not** `skills`. Since Stage 1 modifies the installer, the plan must either:

- accept that installer edits fire the collab template lint and not the skills-sync gate, or
- declare the skills surface *before* `SURFACE_COLLAB_PROTOCOL` (which would then steal `install-ironmem.sh` from the collab gate — probably wrong).

Do not assume the skills gate fires on installer changes. There is an existing test, `test_hook_exact_paths_covers_every_git_hook_module`, that walks the directory rather than trusting a hand-maintained list — worth mirroring for the skills surface.

The base snapshot at `$base_root/$skill` is the **provenance signal** the migration depends on: its presence proves ironmem installed that skill, so removal is safe. Absence means the copy is the user's own (or upstream Superpowers') and must be left alone with a warning.

Note `migrate_legacy_base()` (line 186) already handles relocating older base directories — the new cleanup should run *after* it, so provenance checks see the migrated layout.

## 5. Test conventions — `scripts/test_install_ironmem.py`

- `unittest`, class-based, run as `python3 scripts/test_install_ironmem.py`.
- Installer is exercised via `subprocess.run(["bash", str(INSTALLER), "--skip-build", ...])` with a temp `HOME` and env overrides. The installer honors `CLAUDE_HOME`, `CODEX_HOME`, `CLAUDE_SKILLS_DIR`, `CODEX_SKILLS_DIR` (`install-ironmem.sh:443-457`) — this is how to test cleanup without touching the real `~`.
- `--skip-skills` / `--skip-build` flags keep tests fast.
- `setUpClass` fabricates a fake `target/release/ironmem` when absent, and `tearDownClass` removes it (lines 27-49). Tests skip if `jq` is missing.

## 6. Ordering gotcha — the `docs/` rename

`docs/iron/specs/` **already exists** (it holds the design doc and this file). So the Stage 1 rename cannot be `git mv docs/superpowers docs/iron` — the destination is occupied. It must move **contents**:

```bash
git mv docs/superpowers/plans/* docs/iron/plans/     # 4 files (mkdir the dest first)
git mv docs/superpowers/specs/* docs/iron/specs/     # 2 files
rmdir docs/superpowers/plans docs/superpowers/specs docs/superpowers
```

Existing content: 4 plans (`2026-07-22-collab-token-baseline`, `2026-07-26-review-diff-compression`, `2026-07-27-hybrid-prompt-recall`, `2026-07-29-mcp-response-compression`) and 2 specs (`2026-07-23-remove-ironmem-bases-prefix-design`, `2026-07-26-review-diff-compression-design`).

Cross-references to `docs/superpowers/` must be grepped and updated in the same commit — the vendored skills themselves reference that path (e.g. `writing-plans/SKILL.md` prescribes `docs/superpowers/plans/`), and those skills are being replaced anyway, but `docs/`, `README.md`, and `CONTRIBUTING.md` may also mention it.
